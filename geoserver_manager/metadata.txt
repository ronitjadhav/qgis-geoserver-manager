name=GeoServer Manager
about=Browse, create, edit and delete workspaces, datastores, coverage stores, cascaded WMS/WMTS stores, layers, layer groups and styles on a GeoServer. Configure and seed its tile cache, and edit the server settings. Publish a table, or a vector or raster layer of the open project. Bring layers and styles back into QGIS as WMS, WFS or WMTS. Unlike publishing tools, it manages the whole catalog: stores, layer groups, styles, tile cache and server settings. Lists load in the background and are searchable, sortable and paginated. The user name and password stay in the QGIS settings, or in the QGIS authentication database when you choose so. Built on python-geoservercloud. It bundles python-geoservercloud and xmltodict.
